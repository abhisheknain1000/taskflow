# TaskFlow — Role-Based Task Management System

TaskFlow is a modern full-stack Role-Based Task Management System designed for teams, managers, and organizations to manage workflows efficiently.

It provides secure authentication, role-based dashboards, task assignment, workflow tracking, and scalable team collaboration architecture.

# Role-Based Access Control (RBAC)

## Admin
- Full system access
- Assign managers
- Manage all tasks
- Create tasks
- Update/delete tasks
- Monitor workflow

## Manager
- Create tasks
- Assign tasks to members
- Manage priorities
- Update task workflow
- Delete tasks

## Member
- View assigned tasks only
- Update task status
- Mark tasks completed
